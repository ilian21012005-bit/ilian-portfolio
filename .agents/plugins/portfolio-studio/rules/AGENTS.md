# Portfolio Studio — Routage

Ce plugin complète `AGENTS.md` sans le dupliquer. Utiliser les skills dédiées selon la tâche :

- Refonte UI, suppression d’effets génériques/code mort, design Graphite Monochrome ou audit rédactionnel → lire `.agents/plugins/portfolio-studio/skills/portfolio-anti-slop/SKILL.md`.
- Ajout ou mise à jour de projets, études de cas, traductions FR/EN ou visuels → lire `.agents/plugins/portfolio-studio/skills/portfolio-content/SKILL.md`.
- Validation avant livraison (typecheck, lint, build, contrôle HTTP, revue navigateur) → lire `.agents/plugins/portfolio-studio/skills/portfolio-qa/SKILL.md`.

Exécuter `npm run audit:slop` après toute modification d’UI, de CSS ou de contenu.
