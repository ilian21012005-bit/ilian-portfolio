# Palette du portfolio

La direction Graphite Monochrome a été retenue : fond `#111315`, surface `#1d2023`, texte `#f4f4f1`, texte secondaire `#a6adb2` et accent `#e6e8e7`. Les anciennes variantes de comparaison ont été retirées après validation. Voir `docs/DESIGN_SYSTEM.md` pour les règles actuelles.

`node scripts/check-palettes.mjs` calcule les contrastes des principales combinaisons graphite. Le résultat ne remplace pas un contrôle visuel des états interactifs ni un audit WCAG complet.
